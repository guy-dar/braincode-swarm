<|user|>Can a Zuora custom report be created with columns for usage and adjustments, school parent hierarchy, usage and billed dates, and invoice number and amount?
<|assistant|>Zuora provides custom reports:
1. Navigate to Reporting in Zuora.
2. Click Create New Report in Zuora.
3. Select the Zuora invoice and payment data source.
4. Select the date range.
5. Add columns for usage and adjustments, school parent hierarchy, usage and billed dates, and invoice number and amount.
6. Include the Zuora account data source.
7. Apply filters and groupings.
8. Execute Run Report in Zuora.
It is recommended to schedule the custom report for recurring intervals.
